# 실기기 QA 체크리스트 (1.0)

이 환경에서는 Chromium만 자동으로 테스트할 수 있습니다. iOS Safari와 Android Chrome은 아래 순서대로 직접 확인해 주세요.
문제가 있으면 항목 번호, 기기·OS·브라우저 버전, 화면 캡처를 함께 알려 주시면 됩니다.

- 주소: https://mintsiru.github.io/make-a-baseball-team/
- 예상 시간: 30~40분 (첫 시즌까지)

## 기기 정보

| 항목 | iOS | Android |
|---|---|---|
| 기기 | | |
| OS 버전 | | |
| 브라우저·버전 | Safari | Chrome |
| 홈 화면에 추가해서 열었나 | | |

## 1. 처음 열기

1. 페이지가 열리고 "2026년, KBO 11번째 구단 창단" 화면이 나온다.
2. 화면을 세로·가로로 돌려도 글자가 잘리거나 가로로 밀리지 않는다.
3. 입력칸(구단명)을 눌렀을 때 화면이 확대되지 않는다(iOS).

## 2. 창단

4. 연고지·모기업·구장을 바꾸면 체감 난이도 별이 바뀐다.
5. "창단 신청"을 누르면 진행 표시가 나오고, 리그 생성이 끝날 때까지 화면이 멈춘 듯 보이지 않는다. **걸린 시간을 적어 주세요.** (______초)
6. 튜토리얼 카드가 나오고 "알겠어요"로 넘어간다.

## 3. 겨울 결정

7. "결정할 일"에서 트라이아웃·드래프트·계약금 협상을 "스카우트에게 맡기기"로 넘길 수 있다.
8. 결정 하나를 제출할 때 1초 넘게 멈추는 곳이 있으면 어떤 결정이었는지 적어 주세요.

## 4. 시즌

9. "하루"·"1주"·"한 달"·"정규시즌 끝까지"가 모두 동작하고, 진행 중 표시가 나온다.
10. "정규시즌 끝까지"에 걸린 시간: ______초.
11. 경기 탭에서 기록지·문자중계가 열리고 닫힌다.
12. 선수 이름을 누르면 선수 창이 열리고, 닫기·뒤로 가기로 닫힌다.

## 5. 설정 탭

13. 머리말의 "설정" 버튼과 탭 목록의 "설정"이 같은 화면을 연다.
14. 화면 → 능력치 바 색을 바꾸면 바로 반영된다.
15. 구단 이름 → "가상 이름 세트 넣기" → "이름 적용" 뒤 순위표에 새 이름이 나온다. "실제 이름 넣기"로 되돌아간다.
16. 저장 → "저장소 보호" 상태가 보인다. 홈 화면에 추가해서 연 경우와 브라우저에서 연 경우가 다른지 적어 주세요.

## 6. 저장과 불러오기

17. 앱(탭)을 완전히 닫았다가 다시 열면 같은 날짜에서 이어진다.
18. "진행 파일 저장"으로 파일이 내려받아진다(iOS: 파일 앱에 저장).
19. "불러오기"로 그 파일을 다시 열 수 있다.
20. 설정 → 저장의 "마지막 진행 파일 저장" 시각이 바뀐다.

## 7. 화면

21. 기기의 다크 모드를 켜면 게임도 어두운 화면이 되고, 글자와 구단 색이 잘 읽힌다.
22. 표가 화면보다 넓을 때 표만 옆으로 밀리고 페이지 전체는 밀리지 않는다.
23. 버튼을 누르기 어렵게 작은 곳이 있으면 적어 주세요.

## 8. 오래 하기 (선택)

24. 5시즌 이상 진행한 뒤에도 조작이 눈에 띄게 느려지지 않는다.
25. 설정 → 저장의 "쓰는 저장 공간": ______MB (몇 시즌째: ______).
