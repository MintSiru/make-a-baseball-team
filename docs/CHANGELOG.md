# 변경 이력

버전마다 무엇이 생겼는지 한두 줄로 적었습니다. 자세한 내용은 `ROADMAP.md`의 같은 버전 항목에 있습니다.

`SIM_VERSION`이 바뀐 버전은 같은 시드라도 시뮬레이션 결과가 달라진 버전입니다. 이전 진행 파일은 0.8.0부터 이어 할 수 있습니다.
