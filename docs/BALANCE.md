# 대규모 밸런스 검증 (V1.0)

`scripts/balance.ts`로 리그를 수백 번 20시즌씩 돌려, 한두 시드로는 보이지 않는 치우침을 찾습니다. 계획과 판정 기준은 `docs/PLAN-1.0.md` 4절 D와 8.3절 V8에 있습니다.

- **검증 A (관전 리그)**: 시드 200개 × 20시즌(2026~2045). 우리 구단 없이 10개 구단만 돕니다.
- **검증 B (신생구단)**: 난이도 3 × 모기업 유형 4 × 시드 8개 = 96회, 20시즌. 모든 결정을 스카우트 추천(`autoDecision`)으로 합니다. 사람이 하면 이보다 잘하므로, 결과는 "평균적인 플레이어"의 하한으로 읽습니다.
- 표의 값은 시즌 평균이고, 괄호 안은 시즌들의 5%~95% 범위입니다.

```bash
npx tsx scripts/balance.ts run A 200 20 3 <이름>   # 결과는 .balance/<이름>/ (끊겨도 이어 돌림)
npx tsx scripts/balance.ts run B 8 20 3 <이름>
npx tsx scripts/balance.ts report <이름>
```
