# 현실 규정 조사표

게임의 `rules` 설정값은 이 문서를 근거로 합니다. **기준: 2026 시즌** (게임 시작 연도).

확인 수준

- **확인**: 이번 조사에서 KBO 발표를 인용한 기사로 값을 확인함
- **부분 확인**: 기사에서 일부만 확인했거나 2차 자료(블로그·요약)만 있음
- **미확인**: 기억·일반 지식 기반. 해당 기능을 구현하기 전에 다시 확인해야 함

조사일: 2026-09-25. V0.1 조사 때는 외부 사이트 직접 열람이 막혀 검색 결과로 확인한 기사를 출처로 적었고, V0.2부터는 KBO 공식 사이트를 직접 열람해 보강합니다. KBO 리그 규정 PDF(아래 출처 R0)와 한 번 더 대조하면 좋습니다.
