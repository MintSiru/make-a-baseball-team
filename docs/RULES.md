# 현실 규정 조사표

게임의 `rules` 설정값은 이 문서를 근거로 합니다. **기준: 2026 시즌** (게임 시작 연도).

확인 수준

- **확인**: 이번 조사에서 KBO 발표를 인용한 기사로 값을 확인함
- **부분 확인**: 기사에서 일부만 확인했거나 2차 자료(블로그·요약)만 있음
- **미확인**: 기억·일반 지식 기반. 해당 기능을 구현하기 전에 다시 확인해야 함

조사일: 2026-09-25. V0.1 조사 때는 외부 사이트 직접 열람이 막혀 검색 결과로 확인한 기사를 출처로 적었고, V0.2부터는 KBO 공식 사이트를 직접 열람해 보강합니다. KBO 리그 규정 PDF(아래 출처 R0)와 한 번 더 대조하면 좋습니다.

## 9. 게임용 가정

현실에 선례가 없거나 2026년 제도와 맞춰야 해서 게임이 정한 값입니다. 모두 설정에서 바꿀 수 있게 합니다.

| 항목 | 가정 | 근거 |
|---|---|---|
| 11구단 일정 | 144경기 유지 = 4개 팀과 15경기 + 6개 팀과 14경기. 매 시리즈 한 팀 휴식 | 9구단 체제(2013~2014)의 휴식 팀 방식 + 현행 144경기 |
| 11구단 포스트시즌 | 5개 팀 유지 | 현행 방식 |
| 신생구단 특별지명 | 기존 10개 구단에서 보호 20명 외 1명씩, 1명당 10억 원 | NC·KT 선례. 보호 인원·보상금은 설정값 |
| 신생구단 외국인 특례 | 기존 4명(아시아쿼터 포함)에 +1명 보유, 1군 진입 후 2시즌 | NC·KT 선례를 2026 제도에 맞춤. V0.3에서 확정 |
| 신생구단 1군 엔트리 특례 | +1명, 1군 진입 후 2시즌 | NC 선례(미확인). V0.3에서 확정 |
| 신생구단 가입금·기금·예치금 | 가입금 30억 + 야구발전기금(모기업 유형별) + 예치금 100억 | NC·KT 선례 |
| 신생구단 퓨처스 참가 | 퓨처스 남부 또는 북부 리그에 편입 (연고지에 따라) | 2026 퓨처스 12팀 체제 |
