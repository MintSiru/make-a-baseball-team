# KBO 신구단

2026년, KBO 11번째 구단의 초대 단장이 되어 창단부터 우승까지 구단을 키우는 운영 시뮬레이션입니다. 설치나 서버 없이 HTML 파일 하나로 브라우저에서 실행됩니다.

- **바로 플레이:** https://mintsiru.github.io/make-a-baseball-team/
- **현재 버전:** **2.0.53** · 버전별 요약은 [`docs/CHANGELOG.md`](docs/CHANGELOG.md), 앞으로의 계획은 [`ROADMAP.md`](ROADMAP.md)
- **언어:** 한국어 · English · 日本語

## 시작하는 법

연고지·모기업·구장·난이도를 골라 2026년 7월에 구단을 창단합니다. 창단부터 퓨처스 1년까지 안내하는 튜토리얼로 시작하거나 바로 1군으로 들어갈 수 있고, 구단 없이 리그만 관전할 수도 있습니다.

목표와 조건이 정해진 **시나리오 15종**도 있습니다. 서울의 왕, 재기, 섬그늘에 야구하러 가면, 돌격대의 귀환, 판타지 드래프트, 백 투 더 패스트(2016년 시작), 살려야 한다, 불경기, 불인기 종목, 강철야구, 부상병동, 돌아온 탕아, 통일 리그(이북 연고 6개 구단이 함께 창단하는 16구단 양대 리그), 레거시: 1982 원년(원년 6구단에서 시작해 그해 규정과 그 시대의 이름·구속·재일교포 선수·관중을 따라감) 등입니다. 게임 도중에 불경기·불인기 종목·부상병동·통일 한국 조건을 더할 수도 있습니다.

## 주요 기능

### 창단과 선수단

- 트라이아웃, 우선지명, 특별지명, FA 특례로 첫 선수단 구성
- 해마다 신인 드래프트(드래프트 컴바인과 개인 워크아웃, 후보 투수의 구종까지 보는 후보 표)와 계약금 협상, 육성선수 계약, 격년 2차 드래프트
- 1군 등록·말소, 퓨처스·잔류군 배치를 직접 하거나 감독에게 맡기기
- 라인업 카드로 타순·수비 위치·선발 로테이션 지정(타순이나 위치만 고정할 수도 있음)
- 등번호, 주장, 별명, 은퇴하려는 선수 설득, 실제로 던지고 치는 이도류와 투타 전향

### 한 해의 흐름

- **겨울:** 가을 교육리그·호주 리그(ABL) 유학·해외 마무리캠프(각각 비시즌 결정 단계), 연봉 협상과 연봉 조정, 비FA 다년계약, FA 협상(선수마다 계약금·연봉·옵션·옵트아웃·약속을 제안하고 경쟁 구단과 며칠씩 저울질), 외국인 협상(역제안과 최대 3차까지), 해외 복귀 선수, 구단주에게 FA 영입 부탁
- **봄:** 스프링캠프 계획, 해외 사설 트레이닝 연수, 새 구종 익히기, **시범경기**(개막 전 열흘 동안 구단마다 10경기, 순위·기록과 무관)
- **시즌:** 144경기 정규시즌, 트레이드(7월 31일 마감, 현금·지명권 포함, CPU 구단의 트레이드 제안), 방출·웨이버, 외국인 교체와 부상 대체 외국인, 올스타전과 홈런 더비
- **가을:** 시리즈마다 엔트리를 내고 한 경기씩 선발과 총력전을 정하는 포스트시즌

### 선수

- 숨은 능력과 스카우트·코치 평가의 분리: 성장 타입(초조숙~초만성)과 숨은 특성(천재성·성실성·멘탈·리더십·충성심·논란성·논쟁성·클러치·부상 빈도)을 리포트로 짐작
- 전성기 27~32세, 젊은 선수의 미래 등급은 성적에 따라 오르내림
- 타자는 주 포지션과 부포지션 0~3개, 투수는 주로 던지는 직구와 16가지 구종(슬라이더는 종·횡·고속, 커브는 드롭·슬로우·파워, 너클 커브 포함)을 저마다의 구사율로
- 실제 부상 종류와 재활 기간, 큰 수술 뒤 병역판정, 결혼·출산·슬럼프·선행·구설, 가족 관계, 팬 호감도
- 드물게 일어나는 사건·사고(음주운전, 도핑, 승부조작, 불법 도박 등)와 KBO 징계, 판정 항의와 퇴장, 벤치클리어링
- 입단 전 경력(고교·대학 대회와 청소년 대표팀), 해외 진출 선수의 MLB·NPB·마이너 기록, 선수 이동 기록

### 경기와 기록

- 타석 단위 경기 엔진, 박스스코어, 문자중계와 해설 실황, 투구 위치와 타구 방향이 보이는 실시간 중계
- 좌우·득점권·레버리지·점수 차·주자 상황별 기록, 세이버메트릭스(wRC+, FIP, WAR, 구장 보정), 타구·투구 트래킹(구속·회전·무브먼트, 런 밸류, OAA, 스프린트 속도), 존 바깥까지 보는 핫·콜드 존
- 시상, 기록실, 명예의 전당, 영구결번, 구단 역대 기록, 상대 전적, 업적, 구단 연표
- 국가대표(아시안게임·올림픽·WBC·프리미어12·APBC) 차출과 대회 성적
- 경기·이적·결산 뉴스, 인터뷰, 팬 반응, 우리 구단 소식 팝업

### 구단 운영

- 모기업 목표와 평가, 예산과 시즌권, 시즌 결산(입장·중계권·스폰서·상품 / 연봉·스태프·구장), 경쟁균형세와 외국인 샐러리캡
- 티켓 가격과 마케팅, 감독·코치·스카우트 등 스태프 계약과 경질
- 구장 증축·신축·돔구장, 펜스 높이까지 정하는 구장 편집기, 단계별 시설(실내 연습장·재활센터·데이터 분석실·2군 전용 구장 등)
- 시민구단의 시장 교체, 명명권 구단의 스폰서

### 리그와 규칙

- 2026년부터 모든 구단과 상무가 퓨처스리그를 치르고, 어린 선수는 뛴 만큼 자람
- 원하면 12번째 구단이 라이벌로 창단(단일 리그 또는 드림·매직 양대 리그, NPB식 클라이맥스 시리즈 선택 가능)
- 이사회 의결로 바뀌는 규칙(ABS, 드래프트 추첨제, 양대 리그 등)과 그에 맞서는 선수협, 이사회를 끄면 단장이 직접 정하는 규칙
- 다른 구단은 우승 도전·리빌딩 같은 계획에 따라 트레이드를 판단하고 거절 이유를 말함

### 편의 기능

- 설정 탭: 밝기·글자 크기·능력치 바 색, 화폐 가치(실질 또는 그해 물가), 게임 중 난이도 변경, 구단 이름 편집과 가상 이름 세트
- 자동 저장, 백업과 복구, 진행 파일 저장·불러오기
- 주전 장기 부상·트레이드 마감·가을야구 확정 같은 순간에 멈추기, 결과를 가린 채 중계부터 보기
- 용어·제도·화면을 설명하는 도움말과 결정 화면마다의 요점 안내, 게임 안의 업데이트 노트
- 선택 사항: 본인 API 키로 Claude·GPT·Gemini가 경기 기록을 바탕으로 긴 기사를 다시 씀(키는 탭 메모리에만 두고 저장하지 않음)

리그 기록은 2021~2025 실제 KBO 리그 평균에 맞춰 조정했습니다([`docs/CALIBRATION.md`](docs/CALIBRATION.md)). 리그를 20시즌씩 수백 번 돌려 본 밸런스 검증은 [`docs/BALANCE.md`](docs/BALANCE.md), 재정 설계는 [`docs/FINANCE.md`](docs/FINANCE.md), 규정 조사는 [`docs/RULES.md`](docs/RULES.md)에 있습니다.

## 실행

```bash
npm ci
npm run build   # dist/index.html 하나가 만들어집니다
```

`dist/index.html`을 브라우저로 열면 됩니다. 개발 중에는 `npm run dev`.

GitHub Pages로 배포하려면 저장소 설정 → Pages → Source를 "GitHub Actions"로 바꾸면 됩니다. main 브랜치에 올라갈 때마다 `.github/workflows/pages.yml`이 빌드해서 올립니다.

## 테스트

```bash
npm run typecheck
npm test               # 단위·리그·밸런스·golden 테스트 + Draft Room 1.0.1 동일성 테스트
npm run test:cached    # 같은 테스트, 만든 리그를 캐시해 두 번째부터 빠르게 (소스가 바뀌면 다시 만듦)
npm run build && npm run test:browser   # 실제 Chromium: 창단부터 1군 진입, 4개 화면 크기, axe-core 접근성(WCAG 2 A·AA), 키보드, 다크 모드
npm run i18n:check     # 번역 리소스와 코드 점검
node scripts/mobile-perf.mjs           # 휴대폰 크기 + CPU 4배 감속에서 조작별 시간과 가장 긴 화면 멈춤
```

테스트는 리그를 처음부터 만드는 데 시간이 많이 들어서, CI는 6갈래로 나눠 동시에 돌립니다(`vitest --shard`). 지난 버전 세이브 호환 테스트도 `tests/compat-play-1…4`로 나뉘어 있고, 버전 목록은 `tests/compat/shared.ts` 한 곳에 있습니다. 로컬에서 일부만 다시 돌릴 때는 `LEAGUE_CACHE=1 npx vitest run tests/<파일>`.

밸런스를 바꿀 때:

```bash
npm run calibrate            # 2026 시즌 리그 기록을 2025 실제 값과 비교
npm run report -- seed 2025  # 2015~2025 시즌별 리그 기록·연봉
npx tsx scripts/balance.ts run A 200 20 3   # 관전 리그 200시드 × 20시즌 (결과는 .balance/, 끊겨도 이어 돌림)
npx tsx scripts/balance.ts run B 4 20 3 fa  # 신생구단: 모기업 4 × 4시드 × 난이도 3(같은 리그끼리 짝), FA도 영입하는 단장 (scouts: 스카우트 추천만)
npx tsx scripts/balance.ts report <이름> baseline   # 결과 표, 기준선과 나란히 (docs/BALANCE.md)
npx tsx scripts/balance.ts check <이름>     # 예외·멈춤이 있으면 실패 (GitHub Actions의 수동 실행 "Balance"도 같은 일)
# 결과가 바뀌면 src/core/version.ts의 SIM_VERSION을 올린 뒤
npm run golden:write
```

실제 기록 데이터는 `python3 scripts/fetch-kbo-stats.py 2021 2022 2023 2024 2025`로 다시 받을 수 있습니다.

## 원칙

- **숨은 능력과 공개 평가 분리:** 화면·AI·기사는 스카우팅 리포트만 봅니다(`publicView`).
- **결정성:** 같은 시드와 같은 선택이면 같은 결과. 결과가 바뀌면 `src/core/version.ts`의 `SIM_VERSION`을 올립니다.
- **현실 규정 우선:** 규정 값은 `src/rules/`에 두고 근거를 `docs/RULES.md`에 적습니다. 현실에 없는 것은 게임용 가정이라고 밝힙니다.
- **세이브 호환:** 0.8.0 이후의 진행 파일은 새 버전에서도 이어 할 수 있고, 버전마다 호환 테스트를 둡니다.
- **API 키 보호:** AI 기사용 키는 탭 메모리에만 두고 저장 파일에 넣지 않으며, 모델에는 공개된 사실만 보냅니다.

## 고지

비상업적 팬 제작 게임이며 KBO 및 각 구단과 관련이 없고 승인받지 않았습니다. 구단명·구장명 외의 선수·학교·기록·사건은 모두 가상이고, 2025년까지의 리그 역사도 게임이 만든 가상 역사입니다. 로고와 엠블럼은 쓰지 않으며, 설정 탭에서 구단 이름을 가상 이름 세트로 바꿀 수 있습니다.
